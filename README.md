# LIT · Physical AI Study

[발표 자료 바로 보기](https://mhlee1215.github.io/lit-paper-study/)

**Breaking the Vision–Action Shortcut: Latent Interface Training for Generalizable Robotics Foundation Models**를 읽고 정리한 한국어 발표 자료입니다. 기술 용어와 제목은 영어를 함께 사용합니다.

- 발표자: Minhaeng Lee
- 총 38장: 본 발표·Questions 35장, 보충 자료 3장
- 영상, 그림 확대, 수식, 상세 설명, 예상 질문과 답변 포함

## 사용법

웹사이트에서 스크롤로 탐색하거나 **전체화면 발표**를 선택하세요.

- `←` / `→`: 발표 슬라이드 이동
- `Esc`: 열린 창 닫기 / 발표 종료
- `G`: 목차
- `N`: 발표자 노트
- Questions에서 **답변 보기**: 핵심 답변 표시, **상세보기**: 근거와 설명
- 특정 페이지 공유: 주소 뒤에 `#slide-17`처럼 슬라이드 번호를 추가
